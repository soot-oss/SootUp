# Security Policy

## Supported Versions

Only the latest version of this project receives security updates. Please make sure you are using the most recent release.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.0   | :white_check_mark: |
| 1.3.0   | :x:                |
| 1.2.0   | :x:                |
| 1.1.X   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously and appreciate your help in keeping it safe for everyone.

If you discover a security vulnerability, please report it through GitHub’s private advisory system:

1. Go to the **Security** section of this repository.
    - Direct link: [Report a Vulnerability](https://github.com/soot-oss/SootUp/security/advisories)
2. Click on **“New draft security advisory.”**
3. Provide as much detail as possible, including:
    - A clear description of the issue
    - Steps to reproduce (if applicable)
    - Potential impact
    - Suggested fixes or mitigations (if available)

This ensures that sensitive information is shared privately with the maintainers until a fix is ready.

## What Happens Next

- The maintainers will review your report as quickly as possible.
- If the vulnerability is confirmed, we will work on a patch and coordinate a release.
- You will receive updates throughout the process.

Thank you for responsibly disclosing security issues and helping us protect the community.
